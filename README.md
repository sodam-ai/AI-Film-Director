# AI 영화 연출 실전

[한국어 Markdown](README.md) · [한국어 HTML](README.html) · [English Markdown](README.en.md) · [English HTML](README.en.html)

## 1. 무엇을 할 수 있나요?

한 장면을 여러 **숏**, 즉 카메라가 끊기지 않고 이어지는 화면 단위로 나누고, 각 숏에서 무엇을 보여줄지 정합니다. **콘티**는 이를 장면 순서대로 적은 설계표입니다. **애니매틱**은 콘티에 시간을 붙여 흐름을 미리 확인하는 초안입니다. 이 스킬은 그 시간표를 설계할 수 있습니다. **프롬프트**는 AI에게 주는 요청문이며, **연속성**은 컷을 바꿔도 인물·옷·소품·위치가 자연스럽게 이어지는 것을 말합니다. **VFX**는 촬영 뒤 영상에 더하는 시각 효과입니다.

| 이런 요청을 할 때 | 받는 결과 |
| --- | --- |
| 시나리오를 AI 단편으로 연출하고 싶어요 | 사건과 감정선, 숏 목록, 카메라·인물 동작 |
| 앞 컷과 인물이나 소품이 바뀌어요 | 인물·의상·장소 기준표, 앞 컷 끝과 다음 컷 시작 비교 |
| 영상 생성 도구에 넣을 문장이 필요해요 | 한국어 연출 설명, 영어 입력문, 한 숏씩 나누는 대안 |
| 컷 길이·연기·소리를 맞추고 싶어요 | 콘티 시간표, 연기와 소리 타이밍, 편집·검수 항목 |
| 재시도 비용이나 실사·AI·합성 분담이 궁금해요 | 생성 이력, 예상·실제 크레딧 구분, 숏별 제작 분담 |

영화 추천, 감상문, 일반 PDF 요약, 영화와 무관한 건축 설계는 이 스킬의 적용 범위 밖입니다. 기본 작업은 글로 된 연출안입니다. 실제 영상 파일을 만들려면 생성 도구, 사용 권한과 비용 범위가 별도로 필요합니다.

## 2. 사전 준비물과 필요 프로그램

| 준비물 | 필요한 경우 | 준비 방법 |
| --- | --- | --- |
| Windows PC와 파일 탐색기 | 기본 사용 | 작업 표시줄의 폴더 아이콘을 누르거나 `Windows 키 + E`를 누릅니다. |
| Codex를 사용할 수 있는 계정 및 인터넷 연결 | AI 응답을 받을 때 | 계정에서 Codex를 이용할 수 있는지 확인하고 로그인합니다. |
| ChatGPT 데스크톱 앱 또는 Codex CLI | 기본 사용 | 화면에서 클릭하며 쓰려면 데스크톱 앱을, 명령어로 쓰려면 CLI를 선택합니다. 하나면 됩니다. |
| 설치용 `ai-film-director` 폴더와 짧은 장면 설명 | 기본 사용 | 설치용 폴더의 `SKILL.md`가 보이는지 확인합니다. 처음에는 아래 가상 예제를 써도 됩니다. |
| 웹 브라우저 또는 텍스트 편집기 | 문서 열기 | HTML은 브라우저에서, Markdown(`.md`)은 메모장이나 Markdown 뷰어에서 엽니다. HTML은 인터넷 없이 읽을 수 있습니다. 외부 링크는 인터넷이 필요합니다. |
| Node.js와 npm | npm으로 CLI를 설치할 때 | [Node.js 공식 다운로드](https://nodejs.org/en/download)에서 Windows용 배포판을 받습니다. |
| Python 3, 설치된 Codex CLI 및 `codex.cmd` | 선택 사항. Windows 검증 도구를 재실행할 때 | `python --version`과 `Get-Command codex.cmd`로 확인합니다. 원문 PDF 추출·렌더에는 별도 라이브러리가 필요합니다. |
| 영상 생성·편집 도구 | 실제 영상이 필요할 때 | 도구를 정하고 현재 지원 기능, 이용료, 데이터 처리와 이용권을 확인합니다. |

일상적으로 스킬을 사용할 때 원본 PDF, Python, Git, 별도 API 키, 카카오톡은 설치 준비물이 아닙니다. 스마트폰은 이 Windows용 로컬 설치 절차의 대상에서 제외됩니다. 폴더는 파일을 묶어 놓은 곳이고, 경로는 그 폴더의 주소입니다.

## 3. 다운로드와 설치

### 3.1 Codex 준비

1. 데스크톱을 쓸 경우 [ChatGPT 공식 다운로드](https://chatgpt.com/download/)에서 Windows용 앱을 설치하고 Codex 기능을 사용할 계정으로 로그인합니다.
2. CLI를 쓸 경우 [OpenAI Codex 공식 설치 안내](https://github.com/openai/codex#installing-and-running-codex-cli)에서 Windows 설치 방법을 봅니다. npm 방식의 명령과 로그인 방법은 [5절](#commands)에 있습니다.
3. 이 PC에 이미 스킬이 들어 있는지 먼저 확인합니다. 파일 탐색기의 **상단 주소창**에 `%USERPROFILE%\.agents\skills\ai-film-director`를 입력하고 Enter를 누릅니다. `SKILL.md`, `agents`, `references`가 보이면 [4절](#quickstart)로 이동하세요. 기존 폴더가 불완전하거나 다른 내용이라면 덮어쓰기 전에 출처와 차이를 확인하세요.

### 3.2 설치 파일 받기

이 작업 폴더에서 사용할 사본은 [설치용 ai-film-director 폴더](outputs/ai-film-skill/ai-film-director/)에 있습니다. 이 프로젝트용 공개 다운로드 주소나 배포판은 확인되지 않았습니다. 다른 PC에 파일이 없으면 권리자가 제공한 폴더 또는 승인된 ZIP(여러 파일을 묶은 압축 파일)을 받습니다. ZIP은 마우스 오른쪽 버튼을 눌러 **모두 압축 풀기**를 선택한 뒤, `SKILL.md`가 바로 들어 있는 `ai-film-director` 폴더를 찾습니다.

메신저로 받았을 경우 받은 메시지에서 승인된 파일을 내려받아 **다운로드** 폴더에서 찾으세요. [8절](#files)의 설치 파일 9개가 맞는지 확인합니다. 작업 폴더 전체나 원문 PDF 추출물은 설치에 필요하지 않습니다. 제3자에게 파일을 요청하거나 전달하기 전 [13절](#rights)을 확인하세요.

### 3.3 설치 폴더 복사

1. 파일 탐색기 주소창에 `%USERPROFILE%`을 입력하고 Enter를 누릅니다. 현재 로그인한 사람의 개인 폴더가 열립니다.
2. 이 폴더 안에 `.agents`가 없으면 새 폴더를 만들고 이름을 `.agents`로 정합니다. 그 안에 `skills` 폴더를 만듭니다. 두 폴더가 이미 있으면 그대로 엽니다.
3. 설치용 `ai-film-director` 폴더 자체를 선택하고 `Ctrl + C`로 복사합니다. `%USERPROFILE%\.agents\skills` 안에서 `Ctrl + V`로 붙여넣습니다.
4. 아래 경로를 열어 `SKILL.md`가 직접 보이는지 확인합니다. `.md.txt`로 끝나거나 `ai-film-director` 폴더가 두 번 중첩되면 설치가 제대로 된 경로가 아닙니다. 파일 탐색기 **보기 → 표시 → 파일 확장명**에서 끝 글자를 확인할 수 있습니다.
5. Codex에서 새 대화를 열어 [빠른 시작](#quickstart)을 시험합니다. 새 파일이 목록에 나타나지 않으면 진행 중인 작업을 저장한 뒤 앱이나 CLI를 다시 엽니다. 같은 이름의 스킬을 여러 위치에서 가져오면 선택 목록에 중복이 생길 수 있습니다. [공식 스킬 탐색·재시작 안내](https://learn.chatgpt.com/docs/build-skills)

```text
%USERPROFILE%\.agents\skills\ai-film-director\SKILL.md
```

이 PC에서 확인한 실제 경로는 `C:\Users\PC\.agents\skills\ai-film-director\SKILL.md`입니다. 사용자별 설치 경로를 쓰기 때문에 해당 계정의 여러 작업 폴더에서 스킬을 찾을 수 있습니다.

## 4. 빠른 시작

1. Codex에서 빈 대화를 엽니다. 작업 폴더를 선택하는 화면이 나오면 이 프로젝트 폴더를 선택합니다.
2. 아래 예제를 복사해 대화 입력칸에 붙여넣고 보냅니다. 영상 생성이나 파일 수정을 요청하지 않는 가상 예제입니다.
3. 답변에서 12초가 3개 숏으로 나뉘는지, 시작·종료 상태가 이어지는지, 대사가 없는지, 영어 입력문이 있는지 확인합니다. 자동 선택 자체를 확인하려면 실행 기록의 스킬 파일 읽기와 최종 결과를 함께 확인합니다.

```text
AI 영화의 다음 장면을 12초 3숏 연출안으로 만들어 주세요.
여자가 서랍을 열어 사진을 꺼낸 뒤 창문을 바라봅니다.
각 숏의 시작과 종료 상태, 인물·의상·소품 일관성, 컷 연결을 적어 주세요.
한국어 콘티와 영어 영상 생성 프롬프트를 주세요. 대사는 없습니다.
답변에 글만 작성해 주세요. 파일 변경과 실제 이미지·영상 생성은 하지 마세요.
```

예상 형식은 `0–4초: 서랍 열기 → 4–8초: 사진 꺼내기 → 8–12초: 창문 보기`와 숏별 입력문입니다. 4초씩 나누는 구성은 예시입니다. 3숏의 합이 12초이고 원문 행동의 순서가 맞는지가 확인 기준입니다.

## 5. 실행 방법과 명령어

**데스크톱 앱**에서는 [4절](#quickstart)처럼 입력칸에 문장을 보냅니다. 스킬을 지정하고 싶으면 `$ai-film-director`를 요청 앞에 붙이거나, 앱 사이드바의 **Skills**에서 해당 스킬을 찾습니다. [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)

**CLI**는 글자로 명령을 입력하는 프로그램입니다. Windows 시작 메뉴에서 PowerShell을 열고 아래 명령을 한 줄씩 입력합니다. 프로젝트 폴더로 이동할 때 이 PC의 예시 경로가 다르면 따옴표 안 주소를 자기 폴더로 바꿉니다.

```powershell
codex --version
Set-Location -LiteralPath 'C:\Users\PC\Documents\ChatGPT\제거'
codex
```

`codex`가 설치되어 있지 않고 npm 방식으로 설치할 경우, Node.js를 설치한 뒤 PowerShell을 새로 열어 다음 명령을 실행합니다. 설치 후 새 창에서 `codex --version`을 확인합니다. `codex` 실행 뒤 로그인 안내가 나오면 사용할 계정으로 로그인합니다. [OpenAI Codex 공식 설치 안내](https://github.com/openai/codex#installing-and-running-codex-cli)

```powershell
node --version
npm.cmd --version
npm.cmd install -g @openai/codex
```

| 어디에 입력하나요? | 명령 또는 입력 | 기능 |
| --- | --- | --- |
| PowerShell | `codex --version` | 설치된 CLI 버전을 표시합니다. |
| PowerShell | `codex exec --help` | 설치된 CLI의 한 번 실행 옵션을 표시합니다. |
| 실행 중인 Codex CLI | `/skills` | 지원되는 CLI에서 스킬 목록을 봅니다. |
| Codex 대화 입력칸 | `$ai-film-director`로 시작하는 요청 | 해당 스킬을 직접 지정합니다. |
| Codex 대화 입력칸 | 스킬명 없이 연출·콘티를 설명한 요청 | Codex가 요청의 뜻과 스킬 설명을 비교해 선택할 수 있습니다. |

한 번만 요청하고 종료하는 예시입니다. `--sandbox read-only`는 모델이 실행하는 셸 명령의 파일 쓰기를 제한합니다. `--ephemeral`은 로컬 세션을 저장하지 않는 실행 옵션입니다. 서비스·훅의 모든 로그 보존이나 데이터 처리를 끄는 설정은 [10절](#security)에서 별도로 확인합니다. Git 저장소 밖에서 실행할 때만 `--skip-git-repo-check`가 필요할 수 있습니다.

```powershell
codex exec --ephemeral --sandbox read-only 'AI 영화 장면을 무대사 12초 3숏 콘티와 영어 영상 입력문으로 설계해 주세요. 실제 생성은 하지 마세요.'
```

### 선택 사항. 개발자가 검증을 재실행할 때

다음 명령은 일반 사용자에게 필요하지 않습니다. 프로젝트 최상위에서 실행하며, 기존 기록을 보존해야 하면 먼저 해당 JSON을 별도 위치에 사본으로 저장합니다.

```powershell
python -X utf8 outputs/ai-film-skill/test_host_discovery.py
python -X utf8 outputs/ai-film-skill/test_implicit_live.py
```

- 첫 명령은 별도 로컬 Codex app-server를 시작해 `skills/list`로 발견·활성만 확인하고 `host-discovery.json`을 갱신합니다.
- 둘째 명령은 Windows의 `codex.cmd`로 실제 AI 요청을 실행하고 `implicit-live-v3.json`을 갱신합니다. 계정 사용량이 쓰일 수 있습니다. 내부 대기 한도는 600초입니다.
- 자동 적용 판정에는 이름 없는 입력, `SKILL.md` 및 관련 자료 읽기 성공 기록, 최종 결과, `turn.completed`, CLI 종료 코드 0을 함께 확인합니다. 종료 코드만으로 선택을 판정할 수 없습니다.

## 6. 사용 방법과 워크플로우

| 단계 | 사용자가 주거나 정할 것 | 결과를 볼 때 확인할 것 |
| --- | --- | --- |
| 1. 원문 확인 | 장면 또는 시나리오, 꼭 남겨야 할 대사·사건 | 원문 사실, 연출 제안, 결정되지 않은 항목이 구분됐는지 봅니다. |
| 2. 기준 설정 | 길이, 화면 비율, 인물·옷·장소·소품, 사용할 도구가 있으면 이름 | 비율과 도구가 미정이면 가정이 드러나는지, 참조 파일의 역할이 명확한지 봅니다. |
| 3. 숏 설계 | 관객이 알아야 할 정보와 감정, 원하는 숏 수 | 각 숏에 번호·목표 시간·카메라·행동·소리·시작·종료 상태가 있는지 봅니다. |
| 4. 프롬프트 작성 | 결과 언어와 필요한 형식 | 영어 문장에도 원문 대사와 사건 순서가 유지되는지, 미확인 도구 옵션이 확정처럼 쓰이지 않았는지 봅니다. |
| 5. 시험 제작 | 실제 생성 요청과 도구, 승인된 횟수·예산 | 작은 시험에서 핵심 행동·손·소품을 먼저 봅니다. 실패가 반복되면 숏 분할·컷 조정·실사 합성을 검토합니다. |

짧은 답변만 원하면 “콘티 표만”, 특정 작업이면 “앞 숏과 다음 숏의 손·소품 연결만 검사해줘”처럼 범위를 적습니다. 크레딧은 서비스가 작업량을 세는 단위입니다. 한 번에 3숏이 든 클립을 10크레딧으로 만들고 같은 작업을 6번 다시 했다면 7회 × 10 = 70크레딧입니다. 실제 청구 단위와 남은 크레딧은 제공자의 이용 기록을 확인합니다.

## 7. 작동 방법과 아키텍처

아키텍처는 구성 요소와 작업 순서를 그린 구조입니다.

  → 필요한 references 문서만 읽기

- `SKILL.md` 맨 위 이름과 설명은 탐색과 선택에 사용됩니다. 본문은 결과 작성 순서와 완료 기준을 담습니다.

## 12. 자주 묻는 질문

### PDF를 매번 첨부해야 하나요?

스킬이 참고할 지침은 설치본에 들어 있습니다. 사용하려는 자신의 장면 설명부터 입력하면 됩니다.

### 컴퓨터가 꺼져도 자동으로 영화를 만들나요?

자동 적용은 Codex가 현재 요청을 받을 때 해당 스킬을 선택할 수 있다는 뜻입니다. 생성 예약이나 상시 실행 기능은 제공하지 않습니다.

### 앱에서 작동을 확인했나요?

별도 app-server에서 설치 스킬을 발견했고 실제 자동 적용부터 텍스트 결과까지는 Windows CLI에서 검증했습니다. Desktop UI 새 대화의 직접 시험은 별도로 필요합니다.

### 영어를 몰라도 사용할 수 있나요?

한국어로 요청하고 한국어 콘티와 영어 입력문을 함께 받을 수 있습니다. 영어 입력문을 다른 서비스에 보내기 전에 한국어 설명과 중요한 제약을 함께 확인하세요.

### 원하는 장면만 수정하려면 어떻게 하나요?

“S2의 사진을 잡는 손만 S1에 맞춰줘. 나머지 숏과 시간은 그대로”처럼 수정할 숏과 보존할 조건을 적습니다.

### 카카오톡이나 모바일 앱에 폴더를 넣으면 되나요?

이 안내의 설치 위치는 Windows 사용자의 Codex 탐색 폴더입니다. 메신저는 권한이 있는 파일을 받는 데 사용할 수 있고, 스마트폰 브라우저에서 HTML 문서를 읽을 수 있습니다. 모바일에서 이 Windows 로컬 스킬을 설치하는 절차는 검증하지 않았습니다.
