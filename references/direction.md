# 연출·촬영·서사 기준

근거: 원문 p.5–42, 61–71, 78–80, 86–88. 아래는 원문 내용을 재구성한 작업 기준이다.

## 화면을 결정하는 질문

장면의 사건, 관객이 알 정보, 끝에 남길 감정을 먼저 정한다. 관객이 아직 보거나 듣지 않은 정보를 이미 아는 것으로 가정하지 않는다. 반전을 노출할 시점도 원문과 대조한다.

스토리는 극 중 사건의 시간·인과 순서, 플롯은 관객에게 제시되는 순서로 별도 기록한다. 각색 요청이 없으면 이미 정해진 제시 순서를 보존한다. 장르·도상은 기대를 만드는 단서이며 필수 공식이 아니다. 공포라는 단어만 쓰지 말고 보여줄 대상·빛·소리·상태를 정한다.

## 미장센과 소리

| 요소 | 설계·확인할 내용 |
|---|---|
| 영상 | 누가 무엇을 얼마나 오래 보게 되는가; 시작·행동·결과가 읽히는가 |
| 대사 | 정확한 원문, 화자, 언어, 발화 시점, 상대 반응; 말과 행동의 어긋남·침묵 |
| 음악 | 감정·리듬상의 역할, 시작/종료, 대사를 가리지 않을 구간, 다음 장면 연결 |
| 환경음 | 공간의 위치·거리·잔향을 전달하는 바탕 소리 |
| 폴리·효과음 | 폴리는 동작을 후반에 재현하는 소리; 모든 효과음과 혼동하지 않는다. 원인·접촉·발생 시점 확인 |
| 세트·장소 | 제작 공간과 실제 촬영 장소 구분; 출입구·통로·가구가 동선에 미치는 영향 |
| 소품·대도구 | 행동에 쓰는 물건과 공간을 구성하는 큰 물건; 현장별 분류보다 목록·담당 공유 우선 |
| 의상·분장 | 고정 외형과 젖음·먼지·상처 등 극 중 상태 변화 구분 |
| 조명 | 실제 광원 위치·방향, 명암·부드러움, 피부·단서의 가독성; 색과 감정의 일대일 공식 금지 |

## 숏 크기와 카메라

| 선택 | 읽히게 할 정보 | 주의 |
|---|---|---|
| 익스트림 와이드 | 공간 규모, 작은 인물과 목적지 관계 | 표정·손의 접촉 검증에는 부족할 수 있음 |
| 풀 숏 | 전신 행동, 체중 이동, 발 접촉, 소품과 거리 | 발 미끄러짐·손과 물건 분리 검사 |
| 미디엄 | 상체 행동·표정·상대 반응 | 손·소품이 프레임에 실제 포함되는지 |
| 클로즈업 | 감정 변화, 단서, 손과 물건의 접촉 | 공간 정보가 감소하므로 앞뒤 관계 확인 |
| 눈높이·하이·로우 | 관찰자 위치와 인물이 경험하는 시야 | 권력·취약함 등의 의미는 맥락에 따라 다름 |
| 팬 | 카메라 위치 유지, 수평 방향 회전 | 옆으로 이동하는 트래킹과 구분 |
| 틸트 | 카메라 위치 유지, 위아래 방향 회전 | 카메라 자체의 수직 이동과 구분 |
| 트래킹 | 카메라가 공간 안에서 이동 | 인물과 상대 거리, 경로, 배경 원근 변화 기록 |
| 고정 | 인물의 진입·퇴장·행동으로 화면 변화 | 움직임을 늘리기 전에 목적 충족 여부 판단 |

카메라 이동은 목적 → 출발 위치/구도 → 방향·속도 → 종료 구도로 적는다. 인물 동선은 별도로 기록한다. 여러 회전·이동·복잡한 행동을 한꺼번에 요구하지 않는다. 렌즈·심도는 배경의 단서를 읽을지, 얼굴만 선명하게 할지 등 보이는 효과로 설명한다.

## 행동과 연결

막연한 감정을 관찰 가능한 행동으로 바꾼다. 위험 발견 → 반응 → 출발 → 이동처럼 분석하되 각 행동이 반드시 다른 숏일 필요는 없다. 접촉 → 힘·체중 이동 → 물체 반응의 원인과 결과가 보이는지 확인한다. 작품의 초자연적 예외는 원인과 범위를 명시한다.

축은 시선·이동 관계를 정리하는 수단이다. 축 넘기를 무조건 금지하지 않는다. 방향 변화가 필요하면 넓은 관계 숏·중립 구도·카메라 이동으로 재정위한다. 공간의 첫 화면도 항상 와이드일 필요는 없다. 관객이 필요한 시점에 출입구·위험·목적지 관계를 이해하면 된다.

관객 정보가 같은 컷은 합치거나 줄일 수 있다. 편집용 대안 숏은 목적을 남긴다. 길이는 핵심 행동·대사·반응을 읽을 시간으로 추정하고 실제 재생 후 갱신한다. 평가 우선순위는 사건 전달 → 연속성 → 카메라·빛 → 미세 질감이다.
