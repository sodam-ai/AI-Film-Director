# 콘티·애니매틱·연기·소리·최종 검수

근거: 원문 p.6–8, 25, 41–42, 78–93, 106–107, 123–128.

## 콘티와 시간

콘티 한 칸은 숏 ID / 원문 위치 / 전달 정보 / 구도 / 행동 / 카메라 / 대사 / 화면 안팎의 소리를 담는다. 이미지 완성도와 이야기 전달력을 분리해 평가한다. 시나리오 문단마다 기계적으로 한 숏을 만들지 말고 관객의 정보·시선 전환을 기준으로 나눈다.

애니매틱은 정지 콘티에 임시 길이와 소리를 넣어 사건 순서·정보 가독성·반응 간격을 시험하는 초안이다. 계획표만 만들었다면 재생 가능한 애니매틱을 완성했다고 하지 않는다. 임시 대사·음악·사진은 최종 자료와 구분하고 교체/권리 확인 상태를 남긴다.

- 목표 길이와 실제 채택 구간 길이를 별도 관리한다. 클립 전체 길이를 최종 숏 길이로 계산하지 않는다.
- 겹침 없는 3+4+2+5+3초는 17초. 전체 길이는 실제 사용 구간 합에서 전환 겹침을 빼고 타임라인의 공백 등을 반영한다. 복잡한 트랙 구성은 실제 타임라인을 확인한다.
- 일정 fps에서 프레임 수 = 초 × fps. 24fps 2초는 48프레임. 혼합 fps·가변 fps·드롭프레임 표기는 프로젝트 설정을 확인한다. 소스 숫자만 맞춰서 동작·싱크가 자연스럽다고 판단하지 않는다.
- 대사 길이는 임시 낭독·녹음으로 측정한다. 녹음 전 시간은 추정이다. 반응·침묵·편집 앞뒤 여유도 포함한다.
- 동작 연결은 손·방향·속도·자세를 비교하고 컷점을 몇 프레임 이동해 시험한다. 동작을 중복 재생해야 한다는 고정 규칙은 없다.

## 연기

비트마다 인물의 목표, 드러내려는 태도, 숨기는 반응과 전략의 변화를 적는다. 대사는 허락 없이 추가·수정하지 않는다. 시선 대상, 호흡, 침묵, 손동작을 구체화하되 미세 동작을 과잉 통제하지 않는다. 화자뿐 아니라 듣는 사람의 반응 시간도 설계한다. 얼굴이 아닌 고개·몸 방향도 함께 본다.

| 시간 또는 비트 | 원문 대사 | 목표·숨기는 것 | 시선 대상/변화 | 몸짓·호흡·침묵 | 추정/실측 |
|---|---|---|---|---|---|

## 사운드

| 큐/시간 | 원인·화면 안/밖 | 대사 | 환경음 | 폴리 | 효과음 | 음악 | 연결·권리 상태 |
|---|---|---|---|---|---|---|---|

대사 전달을 먼저 확보하고 다른 소리의 크기·빈도를 조절한다. 화면 밖 소리의 방향·거리·잔향과 이후 시선이 대응하는지 확인한다. 원인을 즉시 보여줄지 나중에 드러낼지는 장면 목적에 따른다. 음악 없이 정보 전달을 시험하되 의도적으로 소리가 서사를 전달하는 장면을 무조건 무음으로 이해해야 한다는 규칙으로 바꾸지 않는다.

별도 녹음 시 일정한 거리·환경, 여러 테이크, 앞뒤 침묵·룸톤과 실제 장비 설정을 기록한다. 입 모양·주요 자음과 효과음 싱크를 별도 조정한다. 길이 차이가 크면 무리한 속도 변경 대신 테이크나 컷을 바꾼다. 현장음과 후시녹음의 잔향·잡음을 비교한다. 가능하면 헤드폰/스피커에서 대사 명료도를 각각 확인하고 실제 사용한 환경만 기록한다.

## 검수와 완료

1. 전체 흐름: 사건·감정·정보·대사가 이해되는가. 처음 보는 검토자가 있다면 이해하지 못한 지점을 기록하되 실제 의견을 받지 않았다면 꾸며 쓰지 않는다.
2. 컷 연결: 인물·시선·손발·의상·소품·광원과 동작 인과를 확인한다.
3. 세부: 접촉·변형·합성 경계·불필요한 흔들림, 자막 오탈자/잘림/표시 시간/대사 대응, 갑작스러운 소리 변화.
4. 출력: 실제 해상도·비율·fps·영상/음성 버전과 배포 사양을 대조한다. 출력 파일을 처음부터 끝까지 시청·청취하고 마지막 프레임·음향 종료까지 확인한다.

기록은 파일/버전, 타임코드, 관찰 현상, 중요도, 수정 담당/행동, 재확인 결과를 포함한다. 필수 사건·대사 누락을 취향보다 먼저 고친다. 수정 후 해당 구간과 앞뒤 연결을 다시 본다. 기술 검사·부분 프레임 확인·전체 시청·청취는 서로 다른 증거이며 대체하지 않는다.
