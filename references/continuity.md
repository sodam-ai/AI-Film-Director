# 인물·공간·소품·컷 연결

근거: 원문 p.9–12, 37–40, 44–59, 72, 76, 80–81, 88, 119–126.

## 기준 시트

- 인물: 코드 + 관찰 가능한 얼굴형·머리·체형·의상·특징, 정본 파일/버전, 승인 상태. 정면/측면/45도·전신 앞/옆/뒤·표정 중 실제 필요한 각도만 계획한다. 기본 외형을 먼저 고정하고 표정을 비교한다. 단순 배경은 기준 시트의 기본 제안이며 사용자 지정 배경을 우선한다.
- 얼굴: 같은 방향·유사 구도로 비교한다. 가려진 특징, 조명 그림자, 렌즈에 따른 비율 차이를 동일성 오류로 단정하지 않는다.
- 의상: 색만 아니라 길이·여밈·주머니·신발·소재·앞뒤 특징. 영구 특성과 특정 장면의 부상·먼지·젖음·찢김을 분리한다. 발생 원인/최초 숏/유지/해소를 작업 순서가 아닌 극 중 순서로 기록한다.
- 참조: 파일별 얼굴/의상/구조/구도/조명/분위기 역할과 반드시 유지할 부분을 적는다. 충돌하면 항목별 정본·우선순위를 정하고 미확인 부분은 미정으로 둔다. 해상도가 낮거나 가려진 곳을 추측해 고정하지 않는다.
- 장소: 문·창·가구·도로·차량·인물·광원의 실제 위치와 기준 방향. 임시 방위는 임시라고 쓴다. 마스터 와이드는 제작 기준이며 최종 삽입 숏이 아닐 수 있다. 한 화면에 담기지 않으면 카메라 위치를 표시한 복수 기준을 쓴다. 보이지 않는 공간을 사실로 확장하지 않는다.
- 동선: 인물과 카메라 각각 출발/종료/방향/상대 거리. 통로·문 여는 공간·가림을 확인한다. 치수 미제공 상태에서 실제 치수를 발명하지 않는다.
- 소품: 코드, 형태·색·크기·문양·방향, 보관 위치, 든 손, 열림/파손 등 상태. 화면 밖 이동은 원인 행동 또는 의도된 생략이 있는지 확인한다.

계획 프롬프트가 아니라 실제 채택 영상의 마지막 상태가 다음 컷의 기준이다. 아직 영상이 없으면 실제 칸은 확인 필요로 둔다. 이전 결과가 계획과 달라도 채택했다면 변경 범위를 기록하고 다음 숏 조건을 갱신한다.

같은 구도 연장은 지원되는 경우 이전 마지막 프레임 참조를 활용한다. 새 앵글은 같은 공간 배치와 상태를 유지한 새 기준 이미지를 설계한다. 반대 앵글이라고 화면 좌우를 강제로 동일하게 하지 않는다. 시간 경과·의도된 생략·상태 변화는 오류와 별도로 적는다.

## 수정 선택

사건을 이해할 수 없는 오류와 주요 소품·인물 불일치를 먼저 고친다. 해당 숏 재생성, 다음 시작 상태 변경, 컷점 조절, 반응/소품 연결 숏 중 기존 채택본의 가치와 원문 보존을 고려해 최소 수정한다. 공통 시트 문제면 영향받는 숏을 열거한다. 이전 버전과 이유를 보존하고 수정 항목뿐 아니라 앞뒤 연결의 새 오류도 점검한다.
