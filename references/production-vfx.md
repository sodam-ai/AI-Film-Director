# 제작 관리와 실사·AI·VFX

근거: 원문 p.95–110, 129–132.

## 생성 이력과 비용

기존 프로젝트의 파일명 체계를 재사용한다. 없다면 장면/숏/클립/시도를 구분하는 간단한 체계를 제안한다. 원본·중간 편집용·채택본을 구분하고 덮어쓰지 않는다. 경로·버전·변경 이유와 프록시의 해상도/사용 구간을 기록한다.

| 작업/클립 ID | 포함 숏 | 시도 | 날짜·모델 | 프롬프트 파일·버전 | 참조 | 실제 설정 | 사용량 | 결과 파일 | 채택·문제·다음 변경 |
|---|---|---|---|---|---|---|---|---|---|

비용은 숏 수가 아닌 실제 생성 작업·출력 과금 단위로 계산한다. 멀티컷 한 작업을 포함된 숏 수만큼 중복 계산하지 않는다. 최초 1회 + 재생성 6회 = 총 7회다. 생성당 단가면 7×단가, 초당이면 각 시도의 실제 과금 길이 합×확인 단가이며 해상도·출력 수 조건도 반영한다. 이미지·음성·음악·업스케일·저장·후반·인력·대여와 작업 시간을 구분한다.

초기 크레딧, 예상/실제 사용, 총 사용, 잔액, 예상 추가분과 계산식을 적는다. 현금과 크레딧의 환산율이 없으면 합산하지 않는다. 미확인 단가·수수료는 0이 아니라 확인 필요다. 견적 확인 날짜와 공식 근거를 남긴다. 예비분은 어려운 숏과 필수 숏에 배분하고 실제 시험 결과로 조정한다. 이 계산은 구매·추가 비용 승인이 아니다.

## 제작 방식 분담

화려함보다 반드시 정확해야 할 사건을 기준으로 실사/생성/합성을 나눈다. 손과 소품 접촉·대사를 실사로, 배경을 생성으로 만드는 것은 선택지이지 필수 경로가 아니다. 배우·장소·소품·예산·시간·카메라 이동·일관성에 따라 결정한다. 사용자 미지정 방식은 제안으로 남긴다.

| 숏·요소 | 정확해야 할 사건 | 실사 | AI | VFX | 입력·담당·연결 지점 | 시험 성공 조건 |
|---|---|---|---|---|---|---|

## 현장 준비와 합성 순서

1. 배우/추가 사물 위치, 시선 높이, 지평선, 카메라 구도·움직임과 주광 방향을 맞춘다. 실제 촬영 기록과 추정 렌즈·높이를 분리한다.
2. 필요한 경우 배우·교체 대상 없는 클린 플레이트를 같은 구도·빛에서 확보한다. 움직이는 카메라·배경·자연광에는 정지 한 장이 충분하다고 가정하지 않는다. 모든 숏에 요구하지 않는다.
3. 움직이는 카메라는 추적 가능한 특징과 표식 제거 계획을 함께 검토한다. 광원·반사·주변색·그림자 참고를 숏/테이크에 연결한다.
4. 선택된 Nuke/After Effects 등 기존 도구에서 숏에 필요한 추적·마스크/로토·배경 복원·요소 합성을 계획한다. 특정 노드/API는 실제 버전에서 확인한다.
5. 먼저 지평선·바닥·원근·상대 크기·발/바퀴의 접촉과 앞뒤 가림을 맞춘다. 큰 왜곡이 필요하면 원본 구도·생성 기준부터 다시 검토한다.
6. 광원 방향·밝기·색·그림자 부드러움·접촉 그림자·반사/투명체의 환경을 맞춘다. 다중 광원·흐린 날의 그림자를 단일 방향으로 강제하지 않는다.
7. 카메라/물체 움직임, 초점·모션블러·입자감·재타이밍·fps 변환을 실제 재생으로 확인한다. 업스케일이 없는 디테일을 정확히 복원한다고 보장하지 않는다. 얼굴·문자는 확대 검토한다.
8. 원본·중간 파일을 보존하고 반복 압축을 줄인다. 최종 매체에서 화면 가장자리·자막·음성을 확인한다.

## 자료와 사용 조건

이미지·영상·목소리·음악·서체별 출처, 사용 범위, 수정/상업/배포 조건, 확인 날짜와 담당을 기록한다. 공개 접근 가능하거나 유료라는 이유만으로 모든 권리가 있다고 가정하지 않는다. 실제 인물의 모습·목소리는 해당 프로젝트의 동의·계약 범위를 확인한다. 미확인은 공개 전에 확인하거나 허용 자료로 교체할 대상으로 표시한다. 이 안내서는 특정 관할의 법적 결론이 아니다.

원문 p.109–110의 밤 대기실·봉투 발견 사례는 교육용 예시다. 신규 프로젝트의 사건이나 의상을 이 예시로 대체하지 않는다.
