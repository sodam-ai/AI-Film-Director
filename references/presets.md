# 요청별 9종 작업 양식

원문 부록 p.111–132를 기능별로 재구성했다. 전부 출력하는 의무 양식이 아니다. 해당 요청에 필요한 입력과 결과만 사용한다. 사용자 제공 사실은 보존하고 미정은 채워 넣어 사실로 만들지 않는다. 아래 역할은 작업 관점이며 별도 에이전트를 호출했다는 뜻이 아니다.

## 1. 전체 연출 패키지 (p.112–116)
입력: 작품/장르/스타일, 원문, 플랫폼, 화면 비율·fps·목표 길이, 생성 단위, 인물·장소·시간·소품·참조, 대사·음향·제외 요소.
출력: 핵심 분석 → 인물/공간/소품 시트 → 시퀀스·숏 리스트 → 한국어 연출 → 영어 생성문 → 연결표 → 실패 시 분할 대안.
숏 필드: ID, 목표 시작/끝/길이, 장소·시간, 인물 코드+외형, 시작 위치, 크기·앵글·이동·속도, 행동·감정 반응, 빛·색·명암, 접촉·무게·관성, 끝 상태, 다음 연결, 대사·소리·주요 오류.
멀티컷은 통합문과 분할안을 함께 설계하며 정확한 전환 시점은 생성 목표로 표시한다.

## 2. 단일 숏 입력문 (p.117–118)
입력: 목표 길이·스타일·비율·지원 형식, 장면 목적, 인물·의상·장소·소품·참조, 시작/행동/끝, 카메라, 빛·물리·지원 음향·금지 오류.
출력: [프롬프트 골격](prompts.md)을 채운 복사 가능한 입력문과 미정/미지원 항목. 대사 문구는 번역·각색하지 않는다.

## 3. 캐릭터·의상 기준 (p.119–120)
입력: 원문·참조, 이름·나이대·외형·기본 의상, 장면별 변화, 필요한 이미지 범위.
출력: 고정 설정표, 극 중 의상/상태 변화표, 필요한 얼굴·전신·표정 각도 제작 계획, 이미지별 한국어 설명·영어 생성문, 동일성 확인표.
원문에 없는 과거·상처·장신구는 제안 또는 미정이다. 불필요한 각도까지 일괄 제작하지 않는다.

## 4. 장소·배경 기준 (p.121–122)
입력: 장소·시간·날씨, 필수 건물/물건, 인물/차량 동선, 기준 방향, 빛, 참조.
출력: 장소 고정표, 실제 위치 관계표, 동선, 광원 위치/방향/색, 마스터 와이드와 필요한 각도별 계획, 영어 이미지 입력문, 공간 검수표.
평면 메모는 영화의 공간 관계용이며 실제 건축 도면·설계 승인으로 표시하지 않는다.

## 5. 스토리보드·애니매틱 (p.123–124)
입력: 원문, 대상 장면, 목표 길이·비율, 생성 단위, 기준 시트, 편집 분위기.
출력: 사건/감정 흐름, 원문↔숏 대응, 숏/시간/구도/행동/카메라/대사/소리 표, 콘티 이미지 설명·영어 입력문, 임시 이미지/대사/효과음 배치표, 숏↔클립 분할, 길이 합과 실제 타임라인 예상.
길이·반응은 녹음 전 추정이다. 20초를 모든 숏 길이로 강제하지 않는다. 계획과 실제 조립된 애니매틱을 구분한다.

## 6. 시작 프레임·컷 연결 (p.125–126)
입력: 이전/다음 숏, 실제 마지막 프레임 또는 확인 범위, 인물·의상·소품, 장소·카메라, 동일 구도/새 앵글/시간 경과.
출력: 이전 끝/다음 시작 표, 유지/변화 비교, 시작 이미지 한국어 설명·영어 입력문, 동작 프롬프트, 편집 오류 목록.
실제 마지막 프레임이 없으면 확인 필요. 동일 구도는 지원 시 프레임 참조, 새 앵글은 같은 상태의 새 기준 구도를 사용한다.

## 7. 연기·대사·사운드 (p.127–128)
입력: 원문 대사, 인물 관계·직전 상황, 길이, 대사/자막 언어, 음악·음성 제작 방식.
출력: 목표/감정, 시간/대사/의도/시선/몸짓/호흡의 비트표, 대사/환경/폴리/효과/음악 큐표, 한국어 연기 지시·영어 생성문, 녹음/싱크 확인, 장면 전후 소리 연결.
음성 기능이 미확인이라면 별도 녹음·후반 편집으로 계획한다. 녹음하지 않은 시간을 실측으로 쓰지 않는다.

## 8. 생성 기록·크레딧 (p.129–130)
입력: 클립과 길이, 가용 크레딧, 모델, 확인 단가·과금 단위, 재생성 계획, 추가 비용.
출력: 클립 계획, 숏↔클립 대응, 시도/프롬프트/참조/모델/실제 사용량/파일/수정 이유, 채택·재작업 목록, 초기/사용/잔액/추가 예상, 계산식·불확실성, 고난도 시험·성공 기준.
멀티컷 중복 과금 계산 금지. 최초 1회+재생성 6회=7회. 가격 미확인은 확인 필요다.

## 9. 실사·AI·VFX 분담 (p.131–132)
입력: 원문·실사 소스, 배우/장소/소품 가용성, 생성할 요소, 후반 도구, 출력 사양, 예산·일정.
출력: 숏별 작업 분담, 촬영 대상, 카메라 메모, 필요한 클린 플레이트·현장 참조, 요소별 이미지/영상 입력문, 선택된 후반 도구의 작업 순서, 원근/빛/그림자/색/블러/질감 검수, 수정·재생성 선택.
실제 미확인 카메라 설정은 추정으로 표시한다. 모든 숏에 동일 합성 방식·클린 플레이트를 강요하지 않는다.
